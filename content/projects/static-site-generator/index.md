# Markdown Static Site Generator

[< Back Home](/)

This is a markdown parsing pipeline that can generate static websites, which I host on GitHub.  

In fact, _this project is powering the site you're looking at right now._
You can find the project's webpage [here](https://tmcausla.github.io/Static-site-generator/).

You can also [download the repo](https://github.com/tmcausla/Static-site-generator) and try it out yourself!

## Tech Stack

- Python
- Linux
- GitHub
- HTML
- CSS

The content is written out in markdown (.md) files:

```
**Bold text** looks like this.
Italics are made with _underscores_.
> It can parse quotes
> across multiple lines
> - Linus Torvalds, probably
## The Good
- Easy to create
- Easy to read
- Easy to grow
## The Bad
1. Not terribly robust compared against modern websites
2. Limited for interactive options
3. Have fun hunting down that one syntax/spelling error
### The Ugly
- The manual parsing pipeline
```
